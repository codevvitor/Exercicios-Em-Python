# Meus Exercícios de Python

Repositório com exercícios de lógica de programação feitos enquanto aprendo Python, com o objetivo de seguir para back-end e, futuramente, cybersegurança.

## Exercícios

| Nº | Arquivo | Descrição |
|----|---------|-----------|
| 01 | `01-par-impar-positivo-negativo.py` | Classifica um número em par/ímpar e positivo/negativo/zero |
| 02 | `02-contador-estatisticas.py` | Guarda números digitados numa lista e mostra estatísticas (quantidade, maior, menor, pares/ímpares) |
| 03 | `03-pedra-papel-tesoura-vidas.py` | Jogo de pedra, papel e tesoura contra o computador, com sistema de vidas |

## Como executar

Com o Python instalado, rode no terminal:

```bash
python nome_do_arquivo.py
```

Exemplo:

```bash
python 03-pedra-papel-tesoura-vidas.py
```
